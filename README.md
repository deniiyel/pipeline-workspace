# Pipeline Workspace: 5 Backend Microservices

Monorepo containing 5 production-ready backend and event-driven microservices.

## Project Runs
- **Run 1: Todo CRUD API** - FastAPI + SQLite
- **Run 2: Multi-Container Service** - Express + Postgres + Redis (Docker Compose)
- **Run 3: JWT Auth Service** - FastAPI + PyJWT + SQLite
- **Run 4: Event Worker** - Python Pub/Sub Worker + Dead Letter Queue
- **Run 5: Metrics API** - FastAPI Time-Series Aggregations
